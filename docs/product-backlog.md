# Product Backlog — Reviste

## Épica 1: Gestión de Usuarios y Cuentas (Área 1)

### Feature 1.1: Autenticación y Acceso
- **US-01:** Como usuario nuevo quiero registrarme con correo o redes sociales para crear mi cuenta en la plataforma. *(Prioridad: Alta | Estimación: 5 pts)*
- **US-02:** Como usuario registrado quiero iniciar y cerrar sesión de forma segura para proteger mis datos. *(Prioridad: Alta | Estimación: 3 pts)*
- **US-03:** Como usuario quiero recuperar mi contraseña en caso de olvidarla para volver a ingresar a mi cuenta. *(Prioridad: Alta | Estimación: 3 pts)*

### Feature 1.2: Perfil y Reputación
- **US-04:** Como usuario quiero editar mi perfil (nombre, foto, biografía, ubicación) para personalizar mi presentación. *(Prioridad: Alta | Estimación: 3 pts)*
- **US-05:** Como vendedor quiero ver el listado de mis prendas publicadas para gestionar mi inventario. *(Prioridad: Alta | Estimación: 5 pts)*
- **US-06:** Como comprador/vendedor quiero calificar y ver la reputación promedio de otros usuarios para realizar transacciones confiables. *(Prioridad: Media | Estimación: 5 pts)*

## Épica 2: Publicación y Búsqueda de Prendas (Área 2)

### Feature 2.1: Gestión de Publicaciones
- **US-07:** Como vendedor quiero publicar una prenda con fotos, precio, talla y estado para ofrecerla en el catálogo. *(Prioridad: Alta | Estimación: 8 pts)*
- **US-08:** Como vendedor quiero ver una vista previa antes de publicar para corregir errores. *(Prioridad: Alta | Estimación: 3 pts)*

### Feature 2.2: Descubrimiento y Filtros
- **US-09:** Como comprador quiero buscar prendas por texto y aplicar filtros (talla, precio, ubicación, categoría) para encontrar rápidamente lo que necesito. *(Prioridad: Alta | Estimación: 8 pts)*
- **US-10:** Como comprador quiero ver el detalle completo de una prenda y su galería de fotos para tomar una decisión de compra. *(Prioridad: Alta | Estimación: 5 pts)*
- **US-11:** Como comprador quiero guardar prendas en favoritos para revisarlas después. *(Prioridad: Media | Estimación: 3 pts)*
